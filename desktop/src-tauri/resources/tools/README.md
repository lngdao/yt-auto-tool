# Local package tools

Platform builds stage a PyInstaller worker under `worker/`, media/OCR executables under `bin/`, Tesseract runtime libraries under `lib/` when needed, and Tesseract language data under `tessdata/`.

The binary payloads are generated by the packaging workflow and are not committed to this repository. `manifest.json` records target versions and SHA-256 hashes. See `docs/packaging.md` for the build workflow and redistribution notes.
